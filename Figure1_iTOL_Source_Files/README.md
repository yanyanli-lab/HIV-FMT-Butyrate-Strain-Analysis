# Figure 1 iTOL Source Files

This directory contains the source files used to generate the circular phylogenetic tree in Figure 1A using the iTOL (Interactive Tree Of Life) platform.

### Files included:
- `Tree_For_iTOL_FINAL.tree`: The phylogenetic tree in Newick format.
- `itol_phylum_strip.txt`: Annotation file for the phylum color strip.
- `itol_butyrate_bars.txt`: Annotation file for the butyrate genomic load bars.
- `itol_hero_symbols.txt`: Annotation file for highlighting the Core 15 strains.
